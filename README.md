# NICE-DEV Portfolio

Portfolio personnel moderne et interactif développé avec React, Vite et Framer Motion.

## 🚀 Technologies utilisées

- **React 18** - Bibliothèque UI moderne
- **Vite** - Build tool ultra-rapide
- **Framer Motion** - Animations fluides
- **Tailwind CSS** - Framework CSS utilitaire
- **React Router** - Navigation SPA

## ✨ Fonctionnalités

- 🎨 Design moderne avec animations fluides
- 📱 Entièrement responsive
- ⚡ Performances optimisées
- 🌟 Effets visuels avancés (particules, glitch, néon)
- 📧 Formulaire de contact fonctionnel
- 🔄 Transitions de page fluides

## 🛠️ Installation

```bash
# Cloner le repository
git clone https://github.com/NICE-DEV226/nice-dev-portfolio.git

# Installer les dépendances
npm install

# Lancer en développement
npm run dev

# Build pour production
npm run build
```

## 🌐 Déploiement sur Vercel

Ce projet est optimisé pour Vercel avec :
- Configuration automatique via `vercel.json`
- Gestion des routes SPA
- Optimisation des assets
- Cache des ressources statiques

```bash
# Déployer sur Vercel
npm run deploy
```
